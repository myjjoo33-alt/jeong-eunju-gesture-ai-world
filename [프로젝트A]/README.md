# 프로젝트A — 얼굴 조각 인터랙티브 전시

## 현재 상태
첫 번째 기본 화면을 만들었습니다. 현재 기능은 얼굴 한 명의 왼쪽 눈, 오른쪽 눈, 코, 입을 각각 네모 영상으로 보여주는 것입니다.

크고 작은 복사본으로 화면을 가득 채우는 연출은 다음 단계입니다.

## PC에서 확인하기
1. Chrome에서 아래 주소를 엽니다.
2. `카메라 켜기`를 누르고 Chrome의 카메라 사용 요청을 허용합니다.
3. 정면을 바라보고 눈을 깜빡이거나 입을 움직여 네 조각의 반응을 확인합니다.

배포 주소: https://myjjoo33-alt.github.io/jeong-eunju-gesture-ai-world/%5B%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8A%5D/

TV 연결은 필요하지 않습니다. 카메라는 버튼을 누른 뒤에만 켜집니다. `카메라 끄기`를 누르거나 다른 탭으로 이동하면 영상 처리를 중단하고 카메라를 끕니다. 전체 화면 버튼도 제공합니다.

카메라가 나오지 않으면 Chrome 주소 왼쪽의 사이트 설정에서 카메라 허용 상태를 확인합니다. 다른 프로그램이 카메라를 사용하고 있다면 해당 프로그램을 종료한 뒤 다시 켭니다.

## 구현과 확인한 범위
- 브라우저 기본 기능과 MediaPipe Face Landmarker를 사용합니다.
- 왼쪽과 오른쪽은 관객 자신의 신체를 기준으로 합니다. 영상은 거울처럼 좌우를 바꾸어 보여줍니다.
- 얼굴을 찾지 못하거나 카메라를 끄면 이전 얼굴 조각을 지웁니다.
- 모델과 실행 파일을 같은 프로젝트 안에 보관하며, 얼굴 영상을 서버로 보내지 않습니다.
- 공식 공개 예제 사진을 영상 입력으로 사용한 검증에서 네 부위 출력, 얼굴 퇴장 시 지우기, 재등장 시 복원, 카메라 종료 및 권한 거절 안내를 확인했습니다.
- 실제 사용자의 웹캠 영상, 실제 동작 속도와 75인치 TV 출력은 아직 직접 확인하지 않았습니다.

## 만들고 싶은 화면
- 웹캠에서 얼굴 한 명을 인식합니다.
- 왼쪽 눈, 오른쪽 눈, 코, 입을 각각 사각형 영상 조각으로 잘라냅니다.
- 네 종류의 조각을 여러 개로 복사하고 크기를 다르게 배치합니다.
- 크고 작은 조각들이 75인치 가로형 TV 화면을 가득 채웁니다.
- 눈 깜빡임과 입 움직임이 복사된 조각에도 실시간으로 반영됩니다.

## 파일 저장 원칙
- 이 프로젝트의 코드, 이미지, 모델, 실행 안내 등은 모두 이 폴더 안에 저장합니다.
- 기존 별요정 트리 등 다른 프로젝트 파일은 이곳으로 옮기지 않습니다.
- 얼굴 영상은 사용자의 PC 안에서 처리하며, 업로드하거나 녹화하지 않습니다.
- 웹캠은 사용자가 켜기 버튼을 누른 뒤 요청하고, 마이크는 사용하지 않습니다.

## 진행 순서
1. 기본 화면을 제작하고 바로 웹 배포 → PC Chrome과 웹캠으로 확인
2. 크고 작은 복사본으로 전체 화면을 채우는 연출을 추가하고 다시 배포 → PC에서 확인
3. TV를 연결할 수 있을 때 화질, 속도, 전체 화면 표시 확인

현재 요청한 단계만 진행하고, 다음 제작 단계는 사용자의 요청 후 시작합니다.

## 배포 방향
- Chrome에서 실행하는 웹페이지로 만듭니다.
- PC 내부 테스트는 localhost 주소를 사용합니다.
- 외부에 배포할 때는 카메라 사용에 필요한 HTTPS 주소를 사용합니다.
- 기존 저장소의 GitHub Pages 설정(`main` 브랜치의 루트)을 유지하고, 이 폴더를 하위 주소로 제공합니다.
- `[프로젝트A]` 폴더의 변경사항을 `main`에 올리면 기존 Pages 설정으로 배포됩니다.

## 파일
- `index.html`: 기본 화면
- `style.css`: 화면 배치와 색상
- `app.js`: 카메라 제어, 얼굴 추적, 영상 조각 출력
- `vendor/mediapipe/`: 공식 얼굴 인식 실행 파일과 라이선스
- `models/face_landmarker.task`: 얼굴 인식 모델
- `THIRD_PARTY.md`: 외부 파일의 출처
- `serve.mjs`: PC 내부 미리보기 서버(선택 사항, Node.js가 설치된 PC에서 실행)

내부 미리보기가 필요하면 이 폴더에서 `node serve.mjs`를 실행하고 `http://127.0.0.1:8765`를 엽니다. 일반 사용자는 위 배포 주소만 열면 됩니다.
