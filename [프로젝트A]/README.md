# 프로젝트A — 얼굴 조각 인터랙티브 전시

## 현재 상태
V2 화면: 최대 두 명을 동시에 인식하여 주인공과 주변 인물의 왼쪽 눈, 오른쪽 눈, 코, 입을 크고 작은 사각형 조각으로 반복해 전체 화면을 채웁니다. 흑백 대비를 높이고, 중앙의 큰 눈은 붉은색으로 강조합니다.

참고 이미지의 반복 배열과 붉은 강조를 적용했습니다. 일부 조각은 180도 뒤집혀 표시됩니다. 모든 조각은 같은 관객의 실시간 영상입니다.

## 파일을 직접 열었을 때

파일 주소(`file:///…/index.html`)에서는 Chrome이 얼굴 인식 코드 불러오기를 차단합니다. 이때는 안내 링크로 배포 주소를 열거나, 아래 내부 미리보기 서버를 실행한 뒤 `http://127.0.0.1:8765`로 접속합니다. 카메라 보안 설정을 해제할 필요는 없습니다.

## PC에서 확인하기
1. Chrome에서 아래 주소를 엽니다.
2. `카메라 켜기`를 누르고 Chrome의 카메라 사용 요청을 허용합니다.
3. 정면을 바라보면 안내창이 숨겨지고 얼굴 조각이 화면을 가득 채웁니다. 눈을 깜빡이거나 입을 움직여 반응을 확인합니다. 오른쪽 위 `카메라 · 설정`으로 안내창을 다시 열어 카메라를 끄거나 전체 화면으로 전환할 수 있습니다.

배포 주소: https://myjjoo33-alt.github.io/jeong-eunju-gesture-ai-world/%5B%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8A%5D/

TV 연결은 필요하지 않습니다. 카메라는 버튼을 누른 뒤에만 켜집니다. `카메라 끄기`를 누르거나 다른 탭으로 이동하면 영상 처리를 중단하고 카메라를 끕니다. 전체 화면 버튼도 제공합니다.

카메라가 나오지 않으면 Chrome 주소 왼쪽의 사이트 설정에서 카메라 허용 상태를 확인합니다. 다른 프로그램이 카메라를 사용하고 있다면 해당 프로그램을 종료한 뒤 다시 켭니다.

## 구현과 확인한 범위
- 브라우저 기본 기능과 MediaPipe Face Landmarker를 사용합니다.
- 왼쪽과 오른쪽은 관객 자신의 신체를 기준으로 합니다. 영상은 거울처럼 좌우를 바꾸어 보여줍니다.
- 얼굴을 찾지 못하거나 카메라를 끄면 이전 얼굴 조각을 지웁니다.
- 모델과 실행 파일을 같은 프로젝트 안에 보관하며, 얼굴 영상을 서버로 보내지 않습니다.
- 공식 공개 예제 사진을 영상 입력으로 사용한 검증에서 네 부위 출력, 얼굴 퇴장 시 지우기, 재등장 시 복원, 카메라 종료 및 권한 거절 안내를 확인했습니다.
- 실제 사용자의 웹캠 영상, 실제 동작 속도와 75인치 TV 출력은 아직 직접 확인하지 않았습니다.

## 만들고 싶은 화면
- 웹캠에서 얼굴 한 명을 인식합니다.
- 왼쪽 눈, 오른쪽 눈, 코, 입을 각각 사각형 영상 조각으로 잘라냅니다.
- 네 종류의 조각을 여러 개로 복사하고 크기를 다르게 배치합니다.
- 크고 작은 조각들이 75인치 가로형 TV 화면을 가득 채웁니다.
- 눈 깜빡임과 입 움직임이 복사된 조각에도 실시간으로 반영됩니다.

## 파일 저장 원칙
- 이 프로젝트의 코드, 이미지, 모델, 실행 안내 등은 모두 이 폴더 안에 저장합니다.
- 기존 별요정 트리 등 다른 프로젝트 파일은 이곳으로 옮기지 않습니다.
- 얼굴 영상은 사용자의 PC 안에서 처리하며, 업로드하거나 녹화하지 않습니다.
- 웹캠은 사용자가 켜기 버튼을 누른 뒤 요청하고, 마이크는 사용하지 않습니다.

## 진행 순서
1. 기본 화면을 제작하고 바로 웹 배포 → PC Chrome과 웹캠으로 확인
2. 크고 작은 복사본으로 전체 화면을 채우는 연출을 추가하고 다시 배포 → PC에서 확인
3. TV를 연결할 수 있을 때 화질, 속도, 전체 화면 표시 확인

현재 요청한 단계만 진행하고, 다음 제작 단계는 사용자의 요청 후 시작합니다.

## 배포 방향
- Chrome에서 실행하는 웹페이지로 만듭니다.
- PC 내부 테스트는 localhost 주소를 사용합니다.
- 외부에 배포할 때는 카메라 사용에 필요한 HTTPS 주소를 사용합니다.
- 기존 저장소의 GitHub Pages 설정(`main` 브랜치의 루트)을 유지하고, 이 폴더를 하위 주소로 제공합니다.
- `[프로젝트A]` 폴더의 변경사항을 `main`에 올리면 기존 Pages 설정으로 배포됩니다.

## 파일
- `index.html`: 기본 화면
- `style.css`: 화면 배치와 색상
- `app.js`: 카메라 제어, 얼굴 추적, 영상 조각 출력
- `mosaic.js`: 빈틈없는 전체 화면 배열, 흑백 처리와 붉은 강조
- `vendor/mediapipe/`: 공식 얼굴 인식 실행 파일과 라이선스
- `models/face_landmarker.task`: 얼굴 인식 모델
- `THIRD_PARTY.md`: 외부 파일의 출처
- `serve.mjs`: PC 내부 미리보기 서버(선택 사항, Node.js가 설치된 PC에서 실행)

내부 미리보기가 필요하면 이 폴더에서 `node serve.mjs`를 실행하고 `http://127.0.0.1:8765`를 엽니다. 일반 사용자는 위 배포 주소만 열면 됩니다.

## V2 — 두 명 참여와 조각 배분
- 얼굴 영상에서 사각형 면적이 가장 큰 사람을 처음 주인공으로 선택합니다.
- 빨간 박스는 주인공의 왼쪽 눈·오른쪽 눈·코·입 중 하나를 무작위로 표시합니다. 약 4초마다 직전 부위와 다른 부위를 선택합니다.
- 주변 흑백 박스에는 다른 참여자의 네 부위를 반복 표시합니다. 혼자 참여하면 본인의 네 부위를 사용합니다.
- 다른 얼굴이 현재 주인공보다 15% 이상 커진 상태가 0.8초 유지되면 주인공을 전환합니다. 현재 주인공이 사라지면 남은 얼굴을 바로 선택합니다.
- 얼굴의 화면 위치를 이용한 임시 추적이며, 사람의 신원을 식별하거나 저장하지 않습니다. 얼굴이 서로 겹치거나 교차할 때 같은 사람을 계속 구별하는 것은 보장하지 않습니다.
- 최대 인원 설정은 2명입니다. 세 명 이상이 카메라에 들어오면 어떤 두 명이 검출되는지 보장하지 않습니다.
- 선택 규칙 검증과 두 얼굴 이미지를 합성한 입력에서 2명 감지·영상 출력·1명으로 감소 시 복귀를 확인했습니다. 실제 2인 웹캠 체험과 속도는 아직 확인하지 않았습니다.
- V2는 현재 PC 내부 주소 `http://127.0.0.1:8765/`에서 확인합니다. GitHub Pages의 V1 공개 배포는 유지합니다.
## V2 — 고개 돌리기로 빨간 박스 증식
- 이번 단계는 고개 동작만 추가했습니다. 손을 뻗어 주변 조각을 늘리는 기능은 아직 추가하지 않았습니다.
- 카메라를 켠 후 주인공은 먼저 정면을 봅니다. 눈 사이에서 코가 차지하는 상대 위치로 좌우 고개 돌림을 추정합니다. 실제 각도를 재는 방식은 아닙니다.
- 정면으로 0.25초 머문 뒤 고개 돌림이 0.15초 유지되면 빨간 박스를 하나 추가합니다. 고개를 돌린 채로 유지하면 추가되지 않습니다. 다시 정면을 보고 돌려야 다음 박스가 생깁니다.
- 박스 수가 늘 때 모든 빨간 박스의 크기는 감소합니다. 새 박스는 화면 안의 무작위 위치 중 기존 박스와 겹침이 적은 곳을 선택합니다. 많아지면 일부 겹칠 수 있습니다.
- 네 개까지는 왼쪽 눈·오른쪽 눈·코·입이 중복되지 않습니다. 다섯 개부터는 네 종류의 부위가 반복됩니다. 부위는 복제 시점과 약 4초 간격으로 무작위 배정합니다.
- 카메라를 끄거나 주인공이 바뀌거나 얼굴이 사라지면 한 개로 초기화합니다.
- 자동 검증 5개 통과: 중복 증식 방지, 위치·거리 이동과 고개 돌림 구분, 순간 흔들림 무시, 증가·축소·화면 경계와 첫 네 부위 중복 방지, 갱신 시점.
- 브라우저의 모의 얼굴 좌표 입력으로 1→2개 증가와 화면 축소·배치를 확인했습니다. 실제 관객의 고개 동작 감도는 웹캠으로 확인해야 합니다.
- 검증 실행: 프로젝트 폴더에서 `node tests/head-interaction.test.mjs`.
